# Prisma Flowers

Sitio de venta de Prisma Flowers (orgullosamente sembrado en Jalisco). HTML estático publicado con GitHub Pages.

- Número de WhatsApp: variable `WHATSAPP` al final de `index.html`.
- Fotos: carpeta `img/` (hero, ramo-10, ramo-5, ramo-mixto, suscripcion, campo).
- Medición para publicidad (opcional): IDs en `assets/analytics.js`.
- Si se compra un dominio: reemplazar `https://donpistolas.github.io/prismaflowers/` en `index.html`, `sitemap.xml` y `robots.txt`, y agregar el archivo `CNAME`.
